# Voiceover scripts: record these

Two ads, two scripts. **Video 2** has the stronger product-first hook and the ₹599 / ₹999 prices; use it as your main ad. **Video 1** opens with the WhatsApp Status hook and works as an A/B test.

## How to record (both videos)

- **Voice:** a friendly Indian woman explaining to a friend or *didi*. Natural, smiling, slightly energetic. Not a news-anchor or "advertisement" voice.
- **Pace:** brisk but clear. "Seconds" is roughly how long each line should take; close is fine.
- **Leave about 1 second of silence between lines.** I'll cut the gaps and sync every scene to your voice, so exact timing doesn't matter.
- **Room:** quiet, fan/AC off, phone 15–20 cm from your mouth, no background music.
- **Numbers:** say *"paanch sau ninyaanve"* (599) and *"nau sau ninyaanve"* (999).
- **Bold words** = say them with a little extra stress.
- **Send:** one file per video, any format (m4a, mp3, wav), named `vo_video1.m4a` and `vo_video2.m4a`. Upload to GitHub → repo `DushyantSingh2003/123` → branch `claude/busy-volta-339z1a` → folder `reseller-ad/audio` → Add file → Upload files.
